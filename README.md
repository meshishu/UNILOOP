# UNI LOOP Website Demo

A responsive, dependency-free front-end demo based on the UNI LOOP project specification and the supplied Next.js project.

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Included
- UNI LOOP branding and LPU-style project identity
- Responsive home/hero section
- Campus categories
- Search, category and price filters
- Product cards and product detail modal
- Wishlist using local browser storage
- Login modal placeholder
- Sell-an-item form placeholder
- How-it-works and trust messaging

## Production path
The uploaded Next.js project remains the recommended production codebase. Connect Firebase Authentication, Firestore and Storage, and add the server-side Razorpay routes described in its README.
